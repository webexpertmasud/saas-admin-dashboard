Introduction

Thank you for purchasing ReachBoard. It is a responsive admin dashboard template built with plain HTML, CSS and JavaScript on top of Bootstrap 5. There is no build step and no framework to learn: open a file in your browser or edit it in any code editor.

What is included

  • 17 ready-to-use pages: dashboard, analytics, orders, users, products, customers, invoices, billing, profile, settings, notifications, empty state, coming soon, 404, login, register and forgot password
  • Dashboard with revenue, traffic and sales charts, recent orders, recent users and an activity timeline
  • Light and dark mode, remembered in the visitor's browser
  • Responsive layout with a collapsible sidebar on mobile
  • Charts powered by Chart.js

All names, emails and numbers in the demo are placeholders.

Getting started

  1. Unzip the download.
  2. Open index.html in your browser. It forwards to the login page.
  3. Click Sign in to open the dashboard. The login form is a visual demo only and does not check credentials.

To use the template on a server, upload the whole folder. Keep the html and assets folders side by side, because pages load files with relative paths such as ../assets/css/style.css.

Customization

Colors. Open assets/css/style.css. The variables at the top control the whole theme.

VariableControls
--inkSidebar background
--accentButtons and chart highlights
--bgPage background
--cardCard background
--lineBorders and dividers
--textMain text color

Dark mode colors are set in the [data-bs-theme=dark] block just below. The charts read their colors from assets/js/main.js, so change #e8912d there to match a new accent.

Logo and name. Search for Reach<i>Board</i> in the files inside html/ and replace it with your own brand name or an <img> tag.

Chart data. Each chart is created in assets/js/main.js. Edit the labels and data arrays to show your own numbers. See the Chart.js documentation for more chart types.

Default theme. The template starts in light mode. To start in dark mode, change saved||'light' to saved||'dark' in assets/js/main.js.

Add a new page

  1. Copy html/settings.html and rename it, for example reports.html.
  2. Change the <title>, the <h1> and the content inside <main class="main">.
  3. In every page, add a link to the sidebar: <a class="nav-link" href="reports.html">Reports</a>
  4. On the new page, add the class active to its own sidebar link.
